# ディベートテンプレート

このディレクトリをコピーして新しいディベートを作成してください。

## 使用手順

### 1. ディレクトリのコピー

```bash
cp -r _template/ your-topic-name/
```

### 2. プレースホルダーの置換

各ファイル内の以下のプレースホルダーを置換してください：

| プレースホルダー | 説明 | 例 |
|-----------------|------|-----|
| `{{TOPIC}}` | テーマ名 | 論理削除（削除フラグ）|
| `{{TOPIC_DESCRIPTION}}` | テーマの説明 | DB 設計における論理削除の是非 |
| `{{POINT_1}}` | 論点 1 | データ保全性 vs 複雑性 |
| `{{POINT_2}}` | 論点 2 | パフォーマンス vs 実装コスト |
| `{{POINT_3}}` | 論点 3 | 法的要件・監査対応 |
| `{{POINT_4}}` | 論点 4 | 開発・保守容易性 |

### 3. 事前調査の実施

`positions/` 内の各ファイルに事前調査結果を記載：

- **affirmative.md**: 肯定派の主張・根拠・参考資料
- **negative.md**: 否定派の主張・根拠・参考資料

### 4. ディベートの実行

AI エージェントに以下のプロンプトを与えて討論を開始：

```
plan.md を読み込み、ディベートを実行してください。
- 肯定派・否定派のサブエージェントを Task tool で起動
- 各論点で 2-3 往復の討論を実施
- 討論内容を debate_log.md に記録
- 最終的にオーケストレータとして判定を下す
```

## ファイル構成

| ファイル | 説明 |
|----------|------|
| plan.md | 討論計画（フェーズ、論点、実行手順） |
| debate_log.md | 討論記録（自動更新） |
| positions/affirmative.md | 肯定派の事前調査 |
| positions/negative.md | 否定派の事前調査 |

## 討論形式

```
オープニング（並列）
    ↓
論点 1: 肯定派主張 → 否定派反論 → 肯定派再反論 → 否定派再々反論
    ↓
論点 2: （同上）
    ↓
論点 3: （同上）
    ↓
論点 4: （同上）
    ↓
クロージング（並列）
    ↓
オーケストレータ判定
```
