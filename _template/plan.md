# {{TOPIC}} 討論システム計画

## 概要

{{TOPIC_DESCRIPTION}} について、2つのサブエージェントが肯定派・否定派に分かれて討論を行う。オーケストレータ（私）が討論を進行・管理し、最終的に判定を下す。

## 討論構成

### 参加者

| 役割 | 担当 | 立場 |
|------|------|------|
| オーケストレータ | メインエージェント（私） | 進行役・**審判** |
| サブエージェント A | Task tool で起動 | **肯定派**（{{TOPIC}} を支持） |
| サブエージェント B | Task tool で起動 | **否定派**（{{TOPIC}} に反対） |

### 討論形式（各論点で反論を繰り返す方式）

| フェーズ | 内容 | 形式 |
|----------|------|------|
| オープニング | 各派の基本主張 | 並列実行 |
| 論点 1: {{POINT_1}} | 主張 → 反論 → 再反論（2-3 往復） | 交互実行 |
| 論点 2: {{POINT_2}} | 主張 → 反論 → 再反論（2-3 往復） | 交互実行 |
| 論点 3: {{POINT_3}} | 主張 → 反論 → 再反論（2-3 往復） | 交互実行 |
| 論点 4: {{POINT_4}} | 主張 → 反論 → 再反論（2-3 往復） | 交互実行 |
| クロージング | 最終主張 | 並列実行 |
| 判定 | オーケストレータによる判定 | 優勢な派を決定 |
| 観客質疑応答 | 観客からの質問・コメント | 任意 |
| 最終結論 | 観客意見を踏まえた再評価 | 改訂版判定 |

### 各論点の進行（2-3 往復）

```
肯定派: 主張 ─────────────────────────────→
                 ↓
否定派: 反論 ←─────────────────────────────
                 ↓
肯定派: 再反論 ────────────────────────────→
                 ↓
否定派: 再々反論 ←─────────────────────────
                 ↓
        （必要に応じてもう 1 往復）
```

### 出力形式

- **リアルタイム表示**: 各ラウンドの結果をチャットに表示
- **ファイル記録**: `debate_log.md` に全討論内容を記録

## 実行計画

### Step 1: 討論記録ファイルの初期化
- `debate_log.md` を作成

### Step 2: オープニング
- 肯定派・否定派を**並列起動**
- 各派の基本主張を収集
- チャットに表示 + ファイルに記録

### Step 3-6: 各論点での討論（4 論点 × 2-3 往復）

各論点で以下を繰り返す：
1. **肯定派の主張** → 記録
2. **否定派の反論**（肯定派の主張を踏まえて）→ 記録
3. **肯定派の再反論** → 記録
4. **否定派の再々反論** → 記録
5. （議論が収束しなければもう 1 往復）

論点リスト：
- 論点 1: {{POINT_1}}
- 論点 2: {{POINT_2}}
- 論点 3: {{POINT_3}}
- 論点 4: {{POINT_4}}

### Step 7: クロージング
- 各派の最終主張を収集
- 並列実行 → 結果収集 → 記録

### Step 8: 判定
- オーケストレータが両派の主張を評価
- 優勢な派を判定し、理由を説明
- 判定結果をファイルに記録

### Step 9: 観客質疑応答（任意）
- 観客（ユーザー）からの質問・コメントを受け付け
- 必要に応じて両派が追加の説明・反論を行う
- 新たな論点や見落としがあれば議論に反映

### Step 10: 最終結論
- 観客からのフィードバックを踏まえて再評価
- 改訂版の総合判定を作成
- 最終結果をファイルに記録
